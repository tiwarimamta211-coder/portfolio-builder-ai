## 🔑 पहला काम: API Key डालें

1. ऊपर दाईं तरफ **"API Key"** बटन पर क्लिक करें
2. अपनी Anthropic API Key डालें (format: `sk-ant-api...`)
3. **"Save Key"** दबाएं
4. Key एक बार सेव होने के बाद बार-बार डालने की जरूरत नहीं

> API Key यहाँ से लें: [console.anthropic.com](https://console.anthropic.com)

## 📋 5 Steps में Portfolio बनाएं

---

### Step 1 — Basic Info (बेसिक जानकारी)

यहाँ अपनी पहचान भरें:

- **First / Last Name** — आपका पूरा नाम
- **Professional Title** — जैसे "Web Developer & Freelancer"
- **Location** — जैसे "Raipur, Chhattisgarh"
- **Email & Phone** — contact details
- **LinkedIn / GitHub URL** — profile links
- **Photo URL** — कोई public image link (optional)
- **Years of Experience & Projects Count** — ये hero section में बड़े नंबर बनकर दिखते हैं

---

### Step 2 — Bio (परिचय)

- **Tagline** — एक छोटी powerful line, जैसे "Building digital solutions that matter"
- **About Paragraph** — खुद लिखें, **या**
- **✦ Generate with AI** बटन दबाएं → Claude आपके लिए professional bio लिख देगा
- **Services** — comma से अलग करके लिखें: `Web Dev, App Dev, Consulting`
- **Availability** — बताएं आप available हैं या नहीं (badge बनता है)

---

### Step 3 — Skills (कौशल)

- **Skill input box** में skill टाइप करें → **+ Add** दबाएं
- या **Enter** key दबाएं
- **✦ Suggest Skills with AI** → Claude आपके title के हिसाब से 10 skills suggest करेगा
- किसी skill को हटाना हो तो chip पर **×** दबाएं

---

### Step 4 — Projects (काम के उदाहरण)

- **✦ Add Project with AI Description** बटन दबाएं
- Project का **Title** और **Tech Stack** भरें
- **✦ AI Write Description** दबाएं → Claude 2 sentences में description लिखेगा
- **Project URL** डालें (optional)
- **Save Project** दबाएं
- इसी तरह 6 projects तक add कर सकते हैं

---

### Step 5 — Theme (डिजाइन)

| Theme | Style |
|---|---|
| Dark Indigo | Premium dark (default) |
| Minimal | Clean white/light |
| Ocean Blue | नीला deep theme |
| Forest Green | हरा nature theme |
| Sunset | Orange/warm theme |
| Royal Purple | Purple luxury theme |

- **Font Style** चुनें (Syne, Inter, Playfair, Mono)
- **Layout** चुनें — Centered या Sidebar Left
- **Sections toggle** — जो section न चाहिए, uncheck करें

## 👁️ Live Preview कैसे काम करता है

- दाईं तरफ आपका portfolio **real-time** में दिखता है
- कुछ भी type करते ही preview update होता है
- **🖥 Desktop** / **📱 Mobile** बटन से view बदलें
- यही design export होती है

---

## ⬇️ Export कैसे करें

1. ऊपर दाईं तरफ **"⬇ Export HTML"** बटन दबाएं
2. एक `.html` file download होगी
3. यह file किसी को भी directly भेज सकते हैं
4. GitHub Pages, Netlify, या hosting पर upload करें — portfolio live हो जाएगा

---

## 💾 Auto-Save

- हर 3 seconds में data automatically **browser में save** होता रहता है
- Page reload करने पर भी सारा data वापस आ जाएगा
- अलग से save button दबाने की जरूरत नहीं

---

## ⚡ Quick Tips

- **पहले Step 1 भरें** → preview में आपका नाम और title दिखने लगेगा
- **AI bio सबसे पहले generate करें** — बाकी sections उसी पर depend करते हैं
- Photo URL के लिए `https://i.pravatar.cc/150?img=5` जैसे free placeholder use कर सकते हैं
- Portfolio को CA firms या freelance clients को directly HTML file भेज सकते हैं
